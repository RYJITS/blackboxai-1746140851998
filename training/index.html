Module 1 : Les bases de l’analyse technique

L’analyse technique est l’étude des mouvements de prix passés pour prévoir les mouvements futurs. Elle repose sur trois principes fondamentaux :

  • Le marché intègre tout (prix, volume, sentiment)
  • Les prix évoluent selon des tendances
  • L’histoire se répète grâce aux comportements humains

Imaginez que vous êtes un détective du marché, cherchant des indices dans les graphiques pour anticiper la suite des événements.

Module 2 : Les chandeliers japonais et patterns visuels

Les chandeliers japonais sont comme des petits personnages qui racontent une histoire. Chaque chandelier montre l’ouverture, la fermeture, le plus haut et le plus bas sur une période donnée.

Quelques patterns clés :

  • Doji : Indécision, ouverture et fermeture proches
  • Harami : Petit chandelier dans un grand, possible retournement
  • Hammer : Signal de retournement haussier

Visualisez-les comme des emojis du marché, chacun avec une émotion différente.

Exercice : Trouvez un graphique avec un Doji et observez ce qui se passe après.

Module 3 : Analyse multi-timeframe (M30, H1, H2, H3, H4)

Analyser plusieurs échelles de temps, c’est comme regarder une ville du haut d’un drone puis à pied. Chaque timeframe donne une perspective différente :

  • M30 : Court terme, mouvements rapides
  • H1 à H4 : Moyen terme, tendances plus stables

La clé est la confirmation entre ces timeframes pour valider une tendance ou un signal.

Module 4 : Stratégie de confirmations multiples (8 signaux)

Notre bot utilise 8 signaux techniques, chacun retournant +1 (bull), -1 (bear) ou 0 (neutre). La stratégie consiste à compter les confirmations haussières et baissières, et n’ouvrir une position que si le nombre minimum de confirmations est atteint.

Signaux intégrés :

  1. Break of Structure (BOS)
  2. Cassure de trendline (SMA20/SMA50)
  3. Double Top / Double Bottom
  4. MACD
  5. RSI
  6. Fibonacci
  7. Support / Résistance
  8. Volume

Chaque signal est expliqué dans le code et la formation.

Exercice : Essayez d’identifier un Double Top sur un graphique et vérifiez si d’autres signaux confirment.
